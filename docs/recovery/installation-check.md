# Installation check

The coordinator at `0x530790` validates the installation root, opens the EA installation key, reads the installation level, optionally scans drives for `mcity.exe`, writes one path for each configured data row, and closes the registry key on every ordinary return. It returns 1 when the install key or level query fails, 2 when the CD scan finds no usable disc, and 0 after preparing the path table.

The coordinator clears the full 8,320-byte path table at entry. It removes one trailing backslash from the root. Level 2 sets the CD-scan bypass flag; level 0 sets the minimal-install flag. For other levels it checks all 26 drives, counts CD-ROM drives, opens `mcity.exe` on each, and keeps the last drive whose file opens. Path row type 1 selects the CD root when the signed level is below1, type2 selects it whenever the level differs from2, and type3 always selects it; other types use the install root.

Primary read-bytes Evidence confirms the shipped pointer and type tables. The stock table has 19 entries: the first row name is an empty string, the remaining rows cover `SaveData\\`, `Data\\Tracks\\`, `Data\\GameArt\\`, `Data\\Parts\\`, the audio folders, menus, text, fonts, frontend art, database, movies, models, skins, GUI and HTML. Only Music (`Data\\Audio\\Music\\`) and Movies (`Data\\Movies\\`) have type 2. There are no type-3 rows, so the shipped level-2 path never reads its uninitialized CD-root local through this table. The coordinator also reads the byte before an empty root buffer when checking its final character, so this model admits only nonempty root results. Arbitrary level-2/type-3 tables remain excluded because their output depends on prior stack bytes.

The 520-case corpus executes the complete original body with explicit returning synthetic services. It compares the result, four globals, every path-table byte and ordered helper arguments. The original bodies for the root, string and integer registry helpers are retained in their own cells; these coordinator cases model their environmental results. Real Windows registry/profile access, drive enumeration, file access and SEH behavior are outside this cell.
