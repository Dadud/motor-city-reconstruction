# Executable INI path initializer

Original `0x51d3c0` is recovered in `native/src/install_registry_path.cpp` and runs directly from the recovered registry constructor. The original body, ASCII-locale uppercase child `0x69bf25`, substring child and reverse-character-search child all execute in the original instruction oracle. GetModuleFileNameA is an explicit synthetic boundary; no actual module pathname or host files are accessed.

Primary retained REA instruction evidence: `ev_95d194c8149e5b23e6a8cdb51da4e938dd089b1ac59e0e0a33fa8ece48ddc2e4` with batch `ev_c9c847e151226245bd076fc5262ab929d8cb048a2e85c8fa45bc0f856fe2ae8e`, in `evidence/install-startup-primary.bundle.json` and snapshot. The pinned target SHA is recorded in the install registry cell. Exact original data bytes observed privately are suffix `\mcotest.ini` at 0x894948 and marker `\NPS` at 0x894958. The uppercase child is interpreted from its retained REA pseudocode; this was previously mislabeled lowercase in planning text.

On API failure the helper resets only the first path byte, retaining any other bytes the boundary wrote. On success it uppercases ASCII letters in place, tests whether the marker occurs anywhere, removes the final component twice for a match or once otherwise, then appends the suffix. With no slash, the existing filename is retained before appending. A marker within a longer directory name still selects the double trim.

Admitted domain: locale global 0xb2b5b4 equals zero, source module result is NUL-terminated within the 259-byte API buffer, and the trimmed path plus 12-byte suffix plus terminator fits the 260-byte owner tail. Unterminated API results and overflowing appends throw native exceptions and are explicitly excluded from original-equivalence claims. The wrapper does not pretend the original unchecked append was safe. Native domain tests run under NDEBUG and verify exact NPS trimming, failed API partial writes, unterminated result rejection and overflowing append rejection.

The expanded registry corpus has 1,280 complete-body cases: 256 standalone path cases, 256 connected constructors using the actual path child, and the existing reopen/predicate/language cases. Eight module fixtures cover normal directories, mixed-case NPS, NPS prefix within a longer component, no slash, root slash, single root directory, long valid input and failed API with partial output. Registry failure and mutation domains remain. Both MSVC and Zig compare every owner byte, result and ordered boundary pre-state image exactly.

Primary literal evidence `ev_ca1aeed137400cd14e165e144848ef6068814911fbcb839fa595e3af765f883e` confirms the suffix and marker at addresses `0x894948` and `0x894958`. Provider Ghidra 12.1.4; target SHA is pinned by the parent cell manifest.
